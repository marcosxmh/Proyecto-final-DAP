# Proyecto: Aplicación de la API de YouTube

## Descripción

Este proyecto es una aplicación desarrollada en Java que utiliza la API de YouTube para proporcionar varias funcionalidades relacionadas con la búsqueda y gestión de contenido de YouTube. La aplicación cuenta con una interfaz de usuario gráfica (GUI) simple y clara, permitiendo a los usuarios interactuar con las funciones principales de manera intuitiva.

## Funcionalidades

1. Registro de usuarios en la API.
   
2. Búsqueda de canales, videos o listas de reproducción.
   
3. Suscripción a canales con notificaciones automáticas sobre nuevos videos.
   
4. Visualización de detalles de canales o videos.
   
5. Historial de búsquedas, con la posibilidad de gestionar y restaurar búsquedas anteriores.
  
6. Gestión de canales favoritos para un acceso rápido.
 
7. Reproducción de videos buscados dentro de la aplicación.

## Tecnologías y herramientas utilizadas

- **Lenguaje de programación:** Java
  
- **Arquitectura:** Modelo-Vista-Controlador (MVC)
  
- **Bibliotecas externas:** json-20240303.jar para manejo de datos JSON.

## API de YouTube

Se utiliza para realizar las consultas y obtener datos relacionados con videos, canales y listas de reproducción.

## Interfaz de usuario

Implementada con clases personalizadas de Java Swing.

## Estructura del proyecto

- **src:** Contiene el código fuente organizado en los siguientes paquetes:
  
- **controller:** Manejo de la lógica de negocio y comunicación con la API.
  
- **model:** Implementación de los patrones de diseño y la estructura de datos.
  
- **view:** Interfaz gráfica para el usuario.
  
- **lib:** Biblioteca externa necesaria para el proyecto.
  
- **resources:** Archivos gráficos y otros recursos utilizados en la aplicación.
  
- **uml:** Diagramas UML que documentan el diseño del sistema.
  
- **doc:** Documentación adicional.

## Requisitos

- Java Development Kit (JDK): Versión 8 o superior.
  
- Claves de la API de YouTube: Asegúrate de incluir tu clave en el código fuente (ya integrada en este caso).

## Ejecución

- Clonar el repositorio o descargar los archivos del proyecto.
  
- Importar el proyecto en tu IDE preferido.
  
- Configurar la biblioteca externa json-20240303.jar en el proyecto.
  
- Ejecutar la clase Main ubicada en src/Main.java.
